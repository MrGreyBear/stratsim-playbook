# 作业例子（第 4 轮，已匿名）

我们课程每一轮由一位组员向董事会汇报。这里是第 4 轮（C4）交的三份作业，名字、组名、班级编号和签名都已经去掉。

| 文件 | 是什么 | 看点 |
|---|---|---|
| `StratSim_Strategy_data_worksheet_C4_example.xlsx` | Strategy data worksheet | 1a 页的 Key Factors 用上一期（C3）的数据；1c 页那张表：跨年项目合并格子，major / minor / 新车 / 降成本各用一种底色，开发中的跑车一直合并到上市那一轮 |
| `StratSim_Financial_data_worksheet_C4_example.xlsx` | Financial data worksheet | Start 到第 4 轮全部填了，第 5、6 轮还没发生所以删掉；每个数字都回模拟器核对过；模板自带的示例页已删除 |
| `One-Page_BoD_Executive_Summary_C4_example.pdf` / `.docx` | One-Page BoD Executive Summary | 三张截图：Results 页、Strategy 表、Financial Summary 表，控制在一页 |

填的时候要注意的地方见 [07 BoD 作业经验](../docs/07_BoD作业经验.md)。

这几份是按我们课程的模板做的，你们的模板和要求可能不一样，以老师的说明为准。直接拿别人的作业去交是不行的，请只拿来参考格式和思路。
