# 01 规则与评分

先搞清楚两件事：游戏怎么算分，系统有哪些硬限制。很多失误不是策略错，是不知道规则。

## 1. 怎么算分

我们课程的最终成绩只看两个数（以你们课程的说明为准）：

| 指标 | 权重 | 说明 |
|---|---|---|
| 累计净利（Cumulative Net Income） | 50% | 6 轮正式比赛的净利加总 |
| 市值（Market Value / Market Cap） | 50% | 最后一年的股价 × 股数，在门户网站的 Results 页看 |

课程资料列出的市值驱动因素是：近 2–3 年的利润、产品组合够深而且有差异化、客户知名度、经销商渠道、负债。**分红和股价本身不在里面**，资料里还专门说成绩和股价无关。

所以：

- 分红不影响净利，也不在市值驱动因素里，对分数最多是零影响。
- 增发会让股数变多，但只要市值涨，就不吃亏。我们 Y1、Y2 各增发 20%，股价照样涨了 8% 和 44%。
- 研发、营销、扩产都是先花钱、后赚钱。最后一两年要算清楚还剩几年能收回来。

Results 页还有一个 **Weighted Score**，按几个指标给 7 家打分，可以用来看自己在行业里的位置。

另外还有 6 个年度财务目标，不计分，但 BoD 汇报要逐项说明：营收增长、毛利率 ≥ 10%、净利率 ≥ 4.5–5%、FCF > 0、ROE ≥ 10%、市值增长。

## 2. 开局状态

练习轮和正式比赛都从同一个 Start 开始（正式比赛不会继承练习轮）：

| 项目 | Start |
|---|---|
| 车型 | 家用车（尺寸 28 / 145 HP）、经济车（12 / 120）、卡车（70 / 190） |
| 销量 | 703K、304K、444K，共 1,452K |
| 产能 | 1,000K（Start 年超产 45%，超产能费 $1,400M） |
| 研发中心 | 2 个 |
| 负债 | 短贷 $6,660M（7.5%） |
| 现金 | 约 $2.1B |
| 股价 | $35.26 × 5 亿股，市值约 $17.6B |

开局最大的问题是：产能太小、负债太高、三款车都不太合身（家用车 28 被 2F 评 too small）。

## 3. 系统硬限制（都是我们实际碰到或测出来的）

### 研发

| 规则 | 我们怎么发现的 |
|---|---|
| 每年最多新建 **1 个**研发中心，当年建、**第二年才能放项目**，最多 5 个 | Y1 想一次建两个，系统只给建一个 |
| 课程要求每个研发中心每年都要有项目 | 课程规定 |
| minor upgrade、降成本：当年就上市 | — |
| major upgrade：占中心 2 年，第二年上市 | Cafav major Y1 开工、Y2 上市 |
| 已有类别的新车：2 年 | Cosmo（家用车）Y3 开工、Y4 上市 |
| 新类别的新车（New Platform）：3 年，**开工那年算第 1 年** | Chow（跑车）Y4 开工，系统显示 Launching Y#6 |
| 车型升级会把旧库存报废；降成本不会 | Y5 Cafav 升级报废 56K 辆，只记了 $89M；Canyon 降成本时库存照卖 |
| 在研发页面建概念车，就能看到 Base Cost、开发费、开发时间，不用花测试次数 | 选配置时先建几个比成本，看完删掉，不然会有 Alerts |
| 同一类别的两个概念车，尺寸和 HP 不能都一样 | 只改 ISSQ 会报错 |
| 对手的新类别计划会在上市前一期的 Industry News 里公布 | 对手宣布做 Utility 的下一年就上市了 |

### 生产和产能

| 规则 | 数字 |
|---|---|
| 扩产每年最多是现有产能的 **50%**，第二年才能用 | 1,500K 时最多 +750K |
| 扩产成本 | 每 10 万辆约 $680–710M（一次性），闲置一年只多约 $68 / 辆折旧 |
| 超产能费 | 超出产能的部分每辆约 $2,200–3,500，超得越多越贵；Manufacturing 页面能直接读出来 |
| Flex | 需求够时自动多产，最多 +10%；**需求不够时没有自动减产**（我们碰到两次） |
| Retooling | 升级的车、增产的车都要付，约 $1,300–1,700 / 每多排 1 辆；记在投资里，按折旧摊 |

### 渠道和财务

| 规则 | 数字 |
|---|---|
| 经销商每年的变动，不能超过**已开业**经销商的 10% | 480 家时最多 ±48；当年新开的要第二年才开业 |
| 增发 | 每年最多是当前市值的 20% |
| CD | 一次最多 $10,000M；利率每年变（我们见过 2.0%–3.5%） |
| 现金不够 | 系统强制借短贷（Y1 时 7.5%） |
| 债券 | 前几年不能提前赎回，练习轮 Y4 才变成 callable |
| 利率 | 负债清零后评级升到 AAA，债券和短贷利率都降 |

### 调研工具

| 工具 | 规则 |
|---|---|
| Test Market | 每年最多 10 次，每次 $100K；价格只能在 baseline 的 ±10% 内，促销最多到 baseline 的 2 倍 |
| Concept Test | 每年最多 10 次，每次 $100K；可以测新车、升级版、开发中的项目 |
| Microsegment / Focus Group | 每个细分市场一份，可以按需要多买（Focus Group $50K / 份） |

## 4. 系统给的数字哪些能信

| 数字 | 能不能信 | 我们的经验 |
|---|---|---|
| 行业销量预测（Microsegment 的 Forecast） | ❌ 偏高 | 正式比赛 Y2–Y4 实际只有预测的 75–77%，练习轮 76–85% |
| Test Market 的份额 | ✅ 很准 | 误差一般 ≤ 0.4 个百分点；全行业都缺货时，实际会比预测高 0.5–0.8 点 |
| Concept Test 的 Likely to buy | ⚠️ 只能用来筛选 | 会夸大价格敏感度（说 $24,500 只有 12% 的人买，实际 $24,000 照样缺货） |
| Pro-Forma 的净利 | ⚠️ 取决于你填的销量 | 练习轮每年高估约 $700M；正式比赛按“Test Market 份额 × 合理的行业规模”填，误差在 ±$450M 内 |
| 细分市场偏好 | ⚠️ 每年会漂移 | 3T 的尺寸偏好：57–77 → 54–74 → 58–78 |
| Economic Outlook | ✅ 要看 | 利率、GDP、油价都会变，Y5 预测 GDP −1.5%、油价 $3.50 → $4.90 |
