# 06 练习轮 vs 正式比赛

练习轮很有用，但它的结论不一定在正式比赛里成立：对手都练过了，规则和环境也可能不一样。我们每一期都记一笔“和练习轮不一样的地方”。

状态：✔️ 和练习轮一样，结论能直接用；🆕 新发现；⚠️ 不一样，要盯着。

## 练习轮的结论在正式比赛里成立的

| 项目 | 结论 |
|---|---|
| 开局数据 | 完全一样，练习轮的开局分析可以直接用 ✔️ |
| 超产能费曲线 | 超 10% 约 $2,200 / 辆，越超越贵 ✔️ |
| 行业销量预测偏高 | 实际只有预测的 75–77% ✔️ |
| Concept Test 夸大价格敏感度 | 定价以 Test Market 为准 ✔️ |
| 升级当年 Test Market 低估需求 | 正式比赛 Cafav 新版实际比测试高 2.7 点 ✔️ |
| 缺货时提价 | 提价 5–10% 后份额基本不变 ✔️ |
| 新车开发时间 | 已有类别 2 年，新类别 3 年 ✔️ |

## 正式比赛才发现的

| 项目 | 练习轮 | 正式比赛 | 怎么应对 |
|---|---|---|---|
| 对手 | 第一年动作不大 | **对手都练过了**：Y1 就有 5 家建第 3 个研发中心、3 家升级车型 | 别指望对手犯低级错误；练习轮的“先发优势”会缩短 🆕 |
| 新建研发中心 | 以为一年能建两个 | 每年最多 1 个 | 第一年就开始建，一年一个 🆕 |
| 扩产上限 | 没碰到过 | 每年最多 +50% | 大扩产分两年 🆕 |
| 经销商上限 | 一次 +48 | 上限是已开业经销商的 10%，当年新开的不算 | 每年都加 🆕 |
| 全行业 Y1 销量 | 练习轮 Y2、Y3 约 10,078–10,339K | 8,961K（−13%） | 每家产能都小，全行业被产量卡住；按“全行业产能 × 约 110%”估 ⚠️ |
| Test Market 的份额 | 误差 ≤ 0.4 点 | 实际高 0.5–0.8 点 | 对手在提价时，测出来的价格再往上加 🆕 |
| Firm Preference | 营销翻倍就上去了 | Y1 营销第 3 多，偏好度第 5 | 偏好度看升级上市 + 营销，不只是营销 🆕 |
| 对手的新类别车 | 练习轮只有一家做 Utility；我们以为新类别要开发 3 年，对手 Y2 宣布最早 Y4 上市 | Y2 宣布，Y3 就有 3 款上市（Industry News 会在上市前一期公布） | 对手已宣布的车按“下一年就上市”算 ⚠️ |
| 新车首年需求 | 练习轮 Canyon 首年份额 47% | 正式比赛 Canyon 首年少卖 95K | 首年排 85–90% ⚠️ |
| Flex | 以为需求不够会减产 | 两次都没减 | 不靠 Flex 防库存 🆕 |
| Test Market 的测试范围 | 没注意 | 价格只能 ±10%，促销最多 2 倍 | 想测更高的价，先把 baseline 改高 🆕 |
| 测试次数 | 没用满过 | 每年 10 次，用完就不能再测 | 留 1–2 次测最终组合 🆕 |
| CD 上限 | 没碰到过 | 一次最多 $10B | 现金再多也只能存这么多 🆕 |
| 经济环境 | 一直平稳 | Y5 预测 GDP −1.5%、油价 $3.50 → $4.90；实际行业 −7.3%，卡车 −19%；Y6 回升 +6.5% | 按持平或下降的市场排产；衰退里贵的车先测降价 🆕 |
| 最后一年压库存 | 没测过 | Pro-Forma 实测：卖不掉的车按成本进库存，净利几乎不降 | 最后一年排满产能 100% 🆕 |
| 超产能费 | 练习轮 Y1 超产 45% 付 $1,544M | 排 105% 先付 $401M、110% 先付 $843M，不管卖不卖得掉 | 只排到 100%，多出来的需求交给 Flex ✔️ |
| Pro-Forma 的 Unit Forecasts | 没用过 | 就是营销页的预计销量，按 Save 才重算 | 用来测“卖不掉会怎样”，测完改回去 🆕 |
| 利率 | 我们只注意到开局短贷 7.5% | 每年变；负债清零后 AAA，短贷 5–6.5%、CD 2–3.5% | 每年看一次 🆕 |

## 每一期出结果后都要补的检查

1. 我们每辆车的实际份额 vs Test Market 预测。
2. 全行业实际销量 vs 系统预测。
3. 对手：谁提价、谁出了新车、谁扩产、谁增发、谁压了库存。
4. 系统有没有出 Special Decisions，规则或日程有没有变。
5. Pro-Forma 的净利 vs 实际净利。
